|---|---|---|
| Date / time / donor or recipient ID | | |

| Time food was prepared (from donor) / time now | | |

| **Human GO / NO-GO** (name, signature) | | |
| Reason for NO-GO (recorded, food NOT moved) | | |
| Record completed (donor, recipient, date, item, quantity) | | |
